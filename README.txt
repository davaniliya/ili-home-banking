ILI NETWORK - ONE CLICK SERVER KIT
==================================

Version base: Minecraft Java 1.21.8 / Paper
Runtime: Java 21+

START:
Double-click START-ILI-NETWORK.bat

Core features included in the custom ILI-Network plugin:
- Register/Login/Logout
- ILI Lobby world generated automatically
- BedWars portal and Survival portal
- /shop
- /skin bridge for SkinsRestorer
- /lobby
- BedWars queue and starter arena
- Basic BedWars beds, teams, respawn/elimination, generators and shop
- Dedicated Survival world

Official compatibility components are fetched by setup.ps1 from their project download endpoints:
Geyser, Floodgate, ViaVersion, ViaBackwards and SkinsRestorer.

The first start can take longer because Paper creates the Minecraft runtime files/worlds.

Java players: 127.0.0.1:25565
Bedrock local test: 127.0.0.1 port 19132 after Geyser finishes setup.
